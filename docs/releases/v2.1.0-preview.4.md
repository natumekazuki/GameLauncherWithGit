# v2.1.0-preview.4

Windows x64向けのプレビュー版です。アプリ表示番号は `2.1.0`、MSIX番号は `2.1.0.21` です。正式版に向けた確認用であり、未確認の条件は下記のとおり残っています。

## preview.3からの変更

- 正式記録中に `Alt+Shift+S` でゲーム窓のクライアント領域を撮影し、最後に受け付けた本文原文へ関連付けます。撮影キーと撮影窓は設定で変更でき、ページ移動・トレイ常駐中も撮影できます。履歴では添付枚数を確認し、画像を開いて切り替えられます。
- 寸法・画素が完全一致する画像を共有し、本文・分類・名前と関連画像を分析用ZIPへ出力できます。ZIPには `manifest.json`、`texts.jsonl`、参照するPNGを収録します。
- 撮影キー変更失敗時の旧キー復旧、撮影失敗・保存中の拒否の通知、空タイトル窓の選択、終了時の受付済み撮影の待機・中止に対応しました。本文削除後の画像の後片付け失敗は本文削除の成否と分け、未参照画像の後片付けを再試行できます。
- 区間に自由なタグを任意で複数付けられます。区間作成時と履歴管理で編集し、同じゲームの既存タグを再利用できます。
- TXT・ZIP出力時に、指定タグの区間だけを含める条件と、指定タグの区間を除外する条件を選べます。各欄の複数タグはいずれか一致、重なる部分は除外優先です。重複区間の本文を二重出力せず、現在の区間・分類・適用済みの名前／本文検索と組み合わせます。
- ゲーム別の有効話者一覧を取得するAPIを追加しました。名前候補を選ぶUIは含みません。

## 互換性と配布

- 更新時にDBの再作成や履歴の自動削除は行いません。ゲーム登録・設定・セーブデータ・同期先、既存のシナリオ履歴・区間を保持します。既存区間はタグなしで利用できます。
- 履歴管理で確定した本文削除・全履歴消去は元に戻せません。必要なデータは更新前や削除前にバックアップしてください。全履歴消去でもゲーム登録・抽出設定・分類定義と他ゲームの履歴は残ります。
- MSIXの名前・発行者・署名証明書はpreview.3と同じで、番号を `2.1.0.20` から `2.1.0.21` へ増やしています。
- アプリ本体、Lunaの32/64bit部品とライセンスを同梱します。対応ソース、固定サブモジュール、pristineなMinHook/uchardet、ビルド手順は添付の `GameLauncherWithGit-v2.1.0-preview.4-source.zip` に含まれます。ビルド時は短いパスへ展開してください。ネイティブ入力はpreview.3から変更していません。

## 確認状況

- 今回の番号更新を含む隔離ソースで、シナリオ・撮影関連の自動テスト54件、Git関連6件がRelease構成で成功しました。Windows Debugビルドと、Windows x64向け署名付きMSIXのRelease発行も成功しました。
- 生成MSIXの署名、展開、Identityの名前・発行者・番号・architecture、Lunaの32/64bit部品とライセンス、アプリ本体・Web資産の同梱を確認しました。インストール済みの実ユーザーデータは操作していません。
- 各実装時の差分・変更テストの独立レビュー結果を確認しました。今回の公開準備による製品差分は番号2ファイルと本ノートのみです。
- 撮影機能と追加修正の実装時には、隔離データと「創作彼女の恋愛公式」で撮影・本文関連・画像閲覧・ZIP出力、キー競合後の旧キー復旧、ゲームのフォーカス維持を確認しています。空タイトル2窓からの手動選択、添付0件からの更新、狭幅の表示も確認しました。今回の配布MSIXをインストールしての再確認ではありません。
- 自由タグは本番Razorと隔離SQLiteを使う非表示ブラウザーで、作成・編集・再読込・再利用と広幅／狭幅表示を確認しました。包含・除外条件を指定したTXTとZIPを実出力し、除外本文が含まれないことを確認しています。ネイティブWebView上でのタグ操作は未確認です。

## 未確認事項・既知の制限

- 更新インストール、配布MSIXでの一連の実機操作、全DPI・混在DPI・複数モニター・排他表示、他作品、長時間・大量画像での性能実測と同時処理の網羅は未確認です。継続する実機・同時処理の検証範囲は [Issue #29](https://github.com/natumekazuki/GameLauncherWithGit/issues/29) で管理しています。確認済みの少数条件を全環境の保証とはしません。
- Windows通知の可視表示と短音の聴感、ネイティブUIからの履歴削除・後片付け再試行は未確認です。通知の呼出し・抑制と、後片付け失敗・再試行・共有画像保護は自動テストで確認しています。
- 本文取得・分類・話者照合はベストエフォートです。全作品対応・全文章の取得・画面との完全一致・未取得文の復元は保証せず、OCR・翻訳は提供しません。HOOKは対象ゲームへDLLを注入するため、信頼できるゲームだけへ接続してください。
- 画像はキー受付時の直近本文原文に紐づく近傍シーンの目印です。画面上のセリフとの厳密な同期や±1行以内は保証しません。撮影対象窓が最前面でない場合は撮影を拒否します。
- タグや部分区間による出力除外は本文へ適用します。ZIPの画像自体は切り抜き・墨消しをしないため、除外した本文が画像内に映っている場合は残ります。画像はセーブデータのGit同期には含みません。
- OpenTelemetry Exporterの既知の中程度の脆弱性警告は [Issue #21](https://github.com/natumekazuki/GameLauncherWithGit/issues/21) で管理しています。現在はファイルログのみを使用し、OTLP exporterは登録していませんが、該当ライブラリは配布物に含まれます。
- 復元時に対象外のAndroidワークロードのサポート終了警告が出ます。また、`mspdbcmf.exe` がないためシンボルパッケージは生成していません。Windows x64のMSIX本体は生成・署名済みです。

動作とデータ保護の詳細は、今回の実装に対応する[シナリオ抽出設計](https://github.com/natumekazuki/GameLauncherWithGit/blob/378d80fb9998032973c246f1d32c9ac2c118922b/docs/design/scenario-extraction.md)を参照してください。
