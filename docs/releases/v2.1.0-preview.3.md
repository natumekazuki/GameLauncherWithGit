# v2.1.0-preview.3

Windows x64向けのプレビュー版です。アプリ表示番号は `2.1.0`、MSIX番号は `2.1.0.20` です。

## preview.2からの変更

- 名前の取得元を指定すれば、受信した名前を話者として判定します。キャラクター名の一覧登録は不要になりました。複数の候補がある場合は未確定とし、既存の手動修正は保持します。
- 保存履歴に名前・本文それぞれの部分一致検索を追加しました。区間・分類と組み合わせ、すべての条件に一致する本文を検索できます。空欄は条件にせず、検索ボタンまたはEnterで適用します。
- 検索結果を200件ずつ閲覧でき、TXTには同じ条件に一致する全件を出力します。大きな履歴の検索処理をUIスレッドから分離しました。
- 選択した本文の削除と、抽出設定を残すゲーム単位の全履歴消去を追加しました。本文の削除は受信原文単位です。同じ原文から分割された本文も削除されるため、確定前に対象と件数を表示します。取得中は先に停止が必要です。
- 「履歴管理」で保存件数の確認、区間の改名・削除ができます。区間だけを削除しても本文は残ります。

## 互換性と配布

- アプリ更新によるDBの再作成・履歴の自動削除は行いません。ゲーム登録、設定、セーブデータ、同期先、シナリオ履歴と区間を維持します。
- 履歴管理で確定した本文削除・全履歴消去は元に戻せません。更新前や削除前に必要なデータをバックアップしてください。全履歴消去でもゲーム登録・抽出設定・分類と他ゲームの履歴は残ります。
- MSIXの名前・発行者・署名証明書はpreview.2と同じで、番号を `2.1.0.19` から `2.1.0.20` へ増やしています。
- GPL-3.0-onlyのアプリ本体と、LunaHook等のネイティブ部品・ライセンスを同梱します。対応ソース、サブモジュール、MinHook/uchardet、ビルド手順は添付の `GameLauncherWithGit-v2.1.0-preview.3-source.zip` に含まれます。ビルド時は短いパスへ展開してください。

## 確認状況

- 配布対象と同じ入力を使う隔離コピーで、シナリオ保存・分類の自動テスト23件、Git関連6件のRelease実行とWindows Debugビルドが成功しました。preview.2以降の差分全体の静的レビューで有効な指摘はありませんでした。
- 実Razor/CSS/JavaScript・模擬接続・隔離SQLiteで、名前登録なしの判定・正式保存、履歴検索・削除・区間管理・TXT出力、キーボード操作と広幅/狭幅の表示を確認しました。実ユーザーデータは使用していません。
- 1MiB/10MiBの合成本文で検索を測定しました。当該Windows Debug環境の全走査は約22ms/約180～270ms、10MiBの後方ページは最大約445msでした。TXT整形・書込み・描画は含まず、他環境の性能保証ではありません。複合条件のTXT全件出力も確認しました。
- Git管理情報のない隔離コピーから、同梱MinHook/uchardetを使って32/64bitのHost・Hook・注入helperをReleaseビルドし、Windows x64向けの署名付きMSIXを生成しました。署名検証・展開、Identityの名前・発行者・番号・architecture、ネイティブ部品・ライセンス・Web資産の同梱を確認しました。
- 更新インストール、ネイティブWebViewでの最終描画・高速入力、今回の改修後の実ゲーム接続・話者精度、他作品・長時間負荷は未確認です。

## 既知の制限

- 取得はベストエフォートです。全作品対応・全文章の取得・画面との完全一致・未取得文の復元は保証せず、OCR・翻訳は提供しません。
- 名前の取得元を特定しても、受信タイミングや連結された名前によって正しく対応づけられない場合があります。区切りのない単一行に複数名が連結すると、一つの名前として扱われる場合があります。
- HOOKはゲームプロセスへDLLを注入します。信頼できるゲームだけへ接続してください。
- OpenTelemetry Exporterの既知の中程度の脆弱性警告は [Issue #21](https://github.com/natumekazuki/GameLauncherWithGit/issues/21) で管理しています。現在はファイルログのみを使用し、OTLP exporterは登録していません。
- 手動スクリーンショットの本文への紐付けは [Issue #22](https://github.com/natumekazuki/GameLauncherWithGit/issues/22) の別機能であり、このプレビューには含まれません。
- 復元時に対象外のAndroidワークロードのサポート終了警告が出ます。また、`mspdbcmf.exe` がないためシンボルパッケージは生成していません。Windows x64のMSIX本体は生成・署名済みです。

動作とデータ保護の詳細は、今回の実装に対応する[シナリオ抽出設計](https://github.com/natumekazuki/GameLauncherWithGit/blob/df72ec5d8fce0616495a0f1e9a6a5f6c2f63b4c5/docs/design/scenario-extraction.md)を参照してください。
