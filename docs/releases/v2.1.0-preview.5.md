# v2.1.0-preview.5

Windows x64向けのプレビュー版です。アプリ表示番号は `2.1.0`、MSIX番号は `2.1.0.22` です。

## preview.4からの変更

- 分析用ZIPの `manifest.ranges` に、保存済み区間のID・名前・元の開始終了位置・タグと、収録本文に対応する交差範囲 `spans` を追加しました（[Issue #30](https://github.com/natumekazuki/GameLauncherWithGit/issues/30)）。
- 無絞込みのゲーム全体出力では、本文削除により空になった区間も含めて全保存区間を収録します。区間・タグ・分類・名前・本文で絞り込む場合は、実際の収録本文と交わる区間だけを含めます。同名・重複区間を統合せず、本文を重複させません。
- 元境界は保持し、実際に収録した位置はUTF-16半開区間の `spans` で示します。除外・検索・削除による穴を補完しません。

## 互換性と配布

- ZIPの `schemaVersion` は **2** です。旧 `selection.range` の区間定義は `ranges` へ移し、選択条件は `selection.rangeId` へ統一しました。ZIPを解析する外部ツールはschemaを確認して対応してください。既存ZIPの変換・上書き、旧schemaでの互換出力は行いません。
- DB移行・再作成・履歴の自動削除はありません。登録情報・設定・セーブデータ・同期先・保存済み本文・区間・タグ・画像を保持します。履歴管理で明示的に確定した削除は元に戻せません。
- MSIXの名前・発行者・署名証明書はpreview.4と同じで、番号を `2.1.0.21` から `2.1.0.22` へ増やしています。
- アプリ本体、Lunaの32/64bit部品とライセンスを同梱します。対応ソース・固定サブモジュール・pristineなMinHook/uchardet・ビルド手順は添付の `GameLauncherWithGit-v2.1.0-preview.5-source.zip` に含みます。ビルド時は短いパスへ展開してください。ネイティブ入力はpreview.4から変更していません。

## 確認状況

- 今回の番号更新を含む隔離ソースで、Capture関連64件・Git関連6件のテストがRelease構成で成功しました。Windows Debugビルド、Windows x64署名付きMSIXのRelease発行と、署名・Identity・ネイティブ部品・ライセンス・Web資産の同梱を確認しました。
- 区間の重なり・同名・隣接・空・区間なし・区間外本文・複数取得回・UTF-16境界と、部分区間・包含除外タグ・分類・名前／本文検索・無一致時の出力を合成DBと実ZIPで検証しました。変更テストを含む独立レビューと指摘修正を完了しています。
- 今回の配布MSIXのインストール、更新インストール、実ゲームを使う一連の操作は未確認です。実ユーザーデータは操作していません。

## 未確認事項・既知の制限

- ネイティブWebViewでのタグ操作、通知の可視表示・音、ネイティブUIからの削除・画像後片付け再試行、全DPI・混在DPI・複数モニター・排他表示・他作品・長時間大量画像・同時処理の網羅は引き続き未確認です。実機検証の残りは [Issue #29](https://github.com/natumekazuki/GameLauncherWithGit/issues/29) で管理しています。
- 本文取得・分類・話者照合はベストエフォートです。全作品・全文章・画面との完全一致・未取得文の復元は保証せず、OCR・翻訳は提供しません。DLL注入を行うため信頼できるゲームだけへ接続してください。撮影はキー受付時の直近本文への近傍シーンの目印で、厳密な同期は保証しません。
- タグや部分区間で本文を除外しても、画像は切り抜き・墨消ししません。除外した本文が画像に映っている場合は残ります。画像はセーブデータのGit同期には含みません。
- OpenTelemetry Exporterの既知の中程度の脆弱性警告は [Issue #21](https://github.com/natumekazuki/GameLauncherWithGit/issues/21) で継続管理しています。現在はファイルログのみを使用しOTLP exporterは登録していませんが、該当ライブラリは配布物に含まれます。
- 復元時の対象外Androidワークロードのサポート終了警告と、`mspdbcmf.exe` 不在によるシンボルパッケージ未生成は継続します。

位置の照合方法は、実装に対応する[分析ZIP契約](https://github.com/natumekazuki/GameLauncherWithGit/blob/cd357f0202af6c7bd243fcfc50a0c422b2c3ea16/docs/design/scenario-extraction.md#手動スクリーンショットと分析用zip)を参照してください。
