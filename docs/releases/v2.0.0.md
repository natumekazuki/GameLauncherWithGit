# v2.0.0

## 主な変更

- Git の所有者が異なるリポジトリについて、選択・登録された worktree のルートに限って Git 実行時に信頼設定を渡し、登録、状態確認、起動前同期、自動同期で使用します。Git のグローバル設定や Windows の所有者・ACL は変更しません。
- Git の日本語出力を UTF-8 として読み取り、失敗時は原因に応じた案内とログ内の詳細を確認できるようにしました。
- モーダル表示中の背面スクロール、フォーカス、未保存内容の破棄確認、通知の表示期間と位置、通知履歴の絞り込みを改善しました。ゲーム編集時のブランチ取得、カードからの履歴表示、起動操作も見直しました。
- 開発・リリース運用と、バージョン・データ互換性の扱いを定義しました。

## 互換性

- Git 2.38.0 以降が必要です。それより古い Git では、アプリ起動時に更新を案内します。
- 関連リポジトリは worktree のルートを指定してください。以前に子フォルダを登録していた場合は、ルートを選択し直す必要があります。
- ゲーム登録、アプリ設定、セーブデータの保存形式は変更していません。

## 確認状況

- Windows 向けビルドと Git 関連の自動テスト 6 件が成功しました。
- Windows x64 向け MSIX の署名、パッケージ名、発行者、バージョンを確認しました。配布用 MSIX のインストール確認は行っていません。
- Windows 上の実際に所有者が異なるリポジトリで、製品のサービスによるメモリ上の登録・状態取得と fetch の dry run を確認しました。実リモートを使う同期は別の隔離コピーで確認しています。
- 製品の UI コンポーネント、CSS、JavaScript を使用したブラウザープレビューで、モーダル、通知、カードなどの操作と描画を確認しました。サービスとゲーム起動にはテスト用の代替実装を使用しています。
- 利用者本人から、今回の修正を反映したアプリで、再起動後の対象リポジトリの同期まで確認済みとの報告を受けています。Codex による実アプリの GUI 操作・再起動確認は行っていません。
- ビルド時に `OpenTelemetry.Exporter.OpenTelemetryProtocol` 1.14.0 の既知の中程度の脆弱性について警告が出ます。アプリの現在のログ設定ではファイル出力を使用し、OTLP exporter は登録していません。
