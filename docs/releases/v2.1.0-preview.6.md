# v2.1.0-preview.6

Windows x64向けのプレビュー版です。アプリ表示番号は `2.1.0`、MSIX番号は `2.1.0.23` です。

## preview.5からの変更

- 同じ作品の連続する本文と話者を保存後に照合し、共通本文と各周回の出現参照を分けて出力します。原文・各回の順序・分岐の一言・その回だけの画像は保持します。訂正・再分割・削除で古い照合を失効させ、処理途中の資料は `matchingComplete=false` で区別します（[Issue #31](https://github.com/natumekazuki/GameLauncherWithGit/issues/31)）。
- ZIPの `manifest.screenshotOccurrences` と共通資料の出現metadataから、本文やPNGを開かずに各原文の画像IDと撮影位置を引けます。添付なしの空配列と、選択外の要素不在を区別します。別の周回の画像を共通本文へ自動転用しません（[Issue #32](https://github.com/natumekazuki/GameLauncherWithGit/issues/32)）。
- 未タグ・区間未設定も含むゲーム全体の観測経路を表示し、分岐・合流から各回の本文・画像へ戻れます。取得中や履歴の出現単位で経路を区切り、指定範囲を独立フローチャートへ分離できます。一時停止中の本文・名前・撮影要求は保存せず、再開後の新しい本文から別経路にします（[Issue #34](https://github.com/natumekazuki/GameLauncherWithGit/issues/34)）。
- 手動場面と本文区間を多対多（Scene–Range N:N）で関連付け、主ラベル・表示番号・章・配置・有向接続を編集できます。観測経路とは別に保存し、本文・画像は複製しません。場面と区間は作品共通タグを使います。包含・除外タグによる既存の出力条件は区間タグを対象とし、場面タグ検索へは拡張しません。
- 二権限のローカルStreamable HTTP MCPを追加しました。初期状態は無効です。`StructureKey` はフロー・出現位置・範囲・分類・画像metadata、`FullKey` は本文・個別話者・画像本体も参照できます。構造キーの応答には本文・個別話者・抜粋・画像path・画像本体のfield自体を含めず、本文・話者検索を許可しません（[Issue #33](https://github.com/natumekazuki/GameLauncherWithGit/issues/33)）。
- MCP両権限とZIP両modeの共通 `material.json.ranges` 相当から、区間ごとの `speakerCounts`（話者名と記録済みDialogue item件数）と `unknownSpeakerDialogueCount` を取得できます。選択結果との実交差を数え、同一区間内の重複clipを二重計上せず、地の文・未判定・Otherを除きます。個別出現の話者は引き続きFull限定です。`manifest.ranges` は位置・タグ・span索引のままで、集計を重複格納しません。

## 互換性とデータ保護

- 新規ZIPは `schemaVersion=3` です。初期選択の構造情報のみには `manifest.json` と `material.json` を収録し、本文・個別話者・画像path・PNG本体を含めません。完全版は出現ごとの `texts.jsonl` と選択画像のPNGも含めます。ZIPとMCPは同じ対象ID・資料版・選択版を使います。
- preview.5のschema 2に対し、共通資料 `material.json`、資料版・照合完了状態、画像出現索引、観測経路、手動場面・作品共通タグ、区間話者集計を追加しました。ID・参照はJSON文字列へ統一し、受信連番・revision・UTF-16位置・長さなどの量は数値を維持します。分類は `Dialogue` / `Narration` / `Other` または `null` です。外部ツールはschemaを確認して対応してください。既存ZIPの変換・上書き、旧schemaでの互換出力やZIP再取込は行いません。
- 既存DBへ照合・経路・手動場面等の保存領域を追加します。既存区間タグは作品共通タグと区間の関連へtransaction内で移し、名前・大小文字の違い・区間ID・作品所属を保持します。DB全体の再作成、登録情報・設定・セーブデータ・同期先・保存済み原文・区間・画像の自動削除は行いません。
- 場面削除では元区間・本文・画像を削除しません。区間削除や全履歴消去では場面との関連だけを外し、手動場面・手編集接続・作品タグを保持します。明示的に確定した本文・全履歴削除は元に戻せません。
- MCPのBearerキーは秘密として扱い、prompt・履歴・共有資料へ貼らないでください。APIの認可はOSのファイル・shell・SSH隔離を提供しません。構造キーにも手入力の場面名・タグや区間単位の話者集計は含まれます。

## 配布と確認状況

- MSIXの名前・発行者・署名証明書はpreview.5と同じで、番号を `2.1.0.22` から `2.1.0.23` へ増やしています。Windows x64 Releaseのビルド・署名付きMSIX発行、署名・Identity・native12ファイル・ライセンス・Web資産を確認しました。
- Windowsは自己完結.NET / ASP.NET Core runtimeとMCP依存を同梱します。配布先でASP.NET Core runtimeを別途導入する必要はありません。CoreCLR・hostpolicy・ASP.NET Core assemblies・deps/runtimeconfigの実同梱を確認しています。
- 本体・固定サブモジュール・pristineなMinHook/uchardet・ライセンス・ビルド手順を `GameLauncherWithGit-v2.1.0-preview.6-source.zip` に収録します。GitHub自動生成ZIPだけでは代用できません。ネイティブ入力はpreview.5から変更せず、公開preview.5の署名済みMSIXから同一の12ファイルを再利用しました。ソースZIPは配布準備commitのtracked本体と固定入力に対応します。短いパスへ展開してビルドしてください。別途作成された取扱説明HTMLは同梱しません。
- 番号更新を含むソースでCapture 107件・MCP 9件・Git 6件のテストがRelease構成で成功しました。実ユーザーDB・キー・画像を使わず、合成データで照合・出現参照・選択境界・実ZIP・MCP transportの二権限・版/scope・場面/タグ移行・区間話者集計を確認しています。
- これに先立つ機能検証では撮影関連2件のtimeoutがあり、原因は未確定です。同じソースと統合先最終の再実行は成功しており、今回の新規結果とは区別します。今回、テスト追加や待機時間の緩和は行っていません。

## 未確認事項・既知の制限

- 今回のMSIXのインストール・更新インストール、実ゲームでの接続・一連の操作、runtime未導入の別PC、外部MCPクライアント製品との接続は未確認です。実ユーザーデータは操作していません。
- ネイティブWebViewでの新機能操作、通知の可視表示・音、全DPI・混在DPI・複数モニター・排他表示・他作品・長時間大量画像・同時処理の網羅は未確認です。Windows実機検証の残りは [Issue #29](https://github.com/natumekazuki/GameLauncherWithGit/issues/29) で管理しています。
- 本文取得・分類・話者照合はベストエフォートです。全作品・全文章・画面との完全一致・未取得文の復元は保証せず、OCR・翻訳は提供しません。DLL注入を行うため信頼できるゲームだけへ接続してください。画像は直近本文の近傍シーンの目印で、厳密な行同期ではありません。出力条件で本文を除外しても画像は切抜き・墨消しせず、画像内の除外本文が残る場合があります。
- OpenTelemetry Exporter 1.14.0の既知の中程度の脆弱性警告3件は [Issue #21](https://github.com/natumekazuki/GameLauncherWithGit/issues/21) で継続管理しています。現在はファイルログのみを登録しOTLP exporterを登録していませんが、対象DLLは配布物に残り、修正済みではありません。2026-11-20の一次advisory再照合では、[disk retryの共有一時領域](https://github.com/open-telemetry/opentelemetry-dotnet/security/advisories/GHSA-4625-4j76-fww9) と [gRPC retryの無制限allocation](https://github.com/open-telemetry/opentelemetry-dotnet/security/advisories/GHSA-mr8r-92fq-pj8p) は1.15.3、[HTTP error bodyの無制限読取](https://github.com/open-telemetry/opentelemetry-dotnet/security/advisories/GHSA-q834-8qmm-v933) は1.15.2で修正されています。3件を含む更新候補は1.15.3以降で、今回依存更新は含みません。未登録という緩和は残余露出を解消しません。
- 復元時の対象外Androidワークロードのサポート終了警告と、`mspdbcmf.exe` 不在によるシンボルパッケージ未生成は継続します。

実装に対応する詳細は、[連続照合・観測経路・手動場面・ZIP契約](https://github.com/natumekazuki/GameLauncherWithGit/blob/385a909209391bb44c1946b09c68bd09e4dc4b04/docs/design/scenario-extraction.md)、[MCPの設定・二権限・資料版](https://github.com/natumekazuki/GameLauncherWithGit/blob/385a909209391bb44c1946b09c68bd09e4dc4b04/docs/design/scenario-mcp.md)、[Windows配布運用](https://github.com/natumekazuki/GameLauncherWithGit/blob/385a909209391bb44c1946b09c68bd09e4dc4b04/docs/design/windows-msix-keyvault-signing.md)を参照してください。
