# v2.1.0-preview.2

Windows x64向けのプレビュー版です。アプリ表示番号は `2.1.0`、MSIX番号は `2.1.0.19` です。

## preview.1からの変更

- 抽出設定を広げ、「接続」「取得元」「判定」のタブに整理しました。下端の操作を固定し、狭い画面でも操作できる配置にしています。
- ウィンドウ名・プロセス名・PID・パスによる検索と、3秒後の前面ウィンドウからのプロセス選択を追加しました。選択だけでは接続せず、「テスト接続」で開始します。接続後の選び直し・失敗後の再試行にも対応しました。
- 取得元ごとの直近5件の受信を比較でき、文章検索・表示の一時停止・受信した名前の登録に対応しました。
- 「判定」で、分割・分類・話者を適用した仕上がりを確認できます。「確定して記録」以降の新しい受信だけを保存し、テスト受信分は破棄します。
- 自由ラベルの追加・名称変更を外しました。名前は話者情報、本文の分類はセリフ・地の文・未判定として扱います。既存の独自分類と保存済み本文、手動修正は保持します。

## 互換性と配布

- 既存のゲーム登録、設定、セーブデータ、同期先、シナリオ履歴と区間を維持します。今回の変更でDBの再作成や保存済み本文の削除は行いません。
- MSIXの名前・発行者・署名証明書はpreview.1と同じで、番号を `2.1.0.18` から `2.1.0.19` へ増やしています。既存の登録情報を使用するため、更新前にデータをバックアップしてください。
- GPL-3.0-onlyのアプリ本体と、LunaHook等のネイティブ部品・ライセンスを同梱したMSIXを配布します。対応ソース、サブモジュール、MinHook/uchardet、ビルド手順は添付の `GameLauncherWithGit-v2.1.0-preview.2-source.zip` に含まれます。
- ソースをビルドする場合は短いパスへ展開してください。深いパスではMSVCのファイル追跡処理が失敗する場合があります。

## 確認状況

- Windows Debugビルド、シナリオ保存・分類の自動テスト18件とGit関連6件のRelease実行が成功しました。
- Git管理情報のない隔離コピーから、同梱MinHook/uchardetを使って32/64bitのHost・Hook・注入helperをReleaseビルドし、Windows x64向けの署名付きMSIXを生成しました。
- MSIXの署名検証・展開が成功しました。名前・発行者の一致、番号の増加、x64パッケージ、32/64bitネイティブ部品とライセンス・Web資産の同梱を確認しました。
- 今回のUI改修は、実Razor/CSS/JavaScriptと模擬接続・隔離SQLiteを使い、1280/700/390px幅で描画・操作を確認しています。プロセス選択、検索、再試行、受信比較、判定、テスト非保存、確定後の保存、キーボード操作を確認しました。
- 更新インストール、ネイティブWebViewでの最終描画、前面ウィンドウから実ゲームのPIDを取得する経路、今回の改修後の実ゲーム接続・精度、他作品・長時間負荷は未確認です。

## 既知の制限

- 取得はベストエフォートです。全作品対応・全文章の取得・画面との完全一致・未取得文の復元は保証せず、OCR・翻訳は提供しません。高速な文章送りでは発言や名前が連結する場合があります。
- テスト表示は最大256取得元、各直近5件・1件1500文字です。省略された長い受信は判定プレビューから除外します。この表示制限で正式記録の原文を切り詰めることはありません。
- HOOKはゲームプロセスへDLLを注入します。信頼できるゲームだけへ接続してください。
- OpenTelemetry Exporterの既知の中程度の脆弱性警告は [Issue #21](https://github.com/natumekazuki/GameLauncherWithGit/issues/21) で管理しています。現在はファイルログのみを使用し、OTLP exporterは登録していません。
- 復元時に対象外のAndroidワークロードのサポート終了警告が出ます。また、`mspdbcmf.exe` がないためシンボルパッケージは生成していません。Windows x64のMSIX本体は生成・署名済みです。

動作とデータ保護の詳細は、今回の実装に対応する[シナリオ抽出設計](https://github.com/natumekazuki/GameLauncherWithGit/blob/5879f2b3ca67b0a3bcf2b560b1b66695d05b78f0/docs/design/scenario-extraction.md)を参照してください。
