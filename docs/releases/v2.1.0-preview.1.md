# v2.1.0-preview.1

Windows x64向けのプレビュー版です。アプリ表示番号は `2.1.0`、MSIX番号は `2.1.0.18` です。

## 主な変更

- HOOKによるゲーム本文とキャラクター名の取得、保存、修正、TXT出力を追加しました。取得候補と接続先をゲーム別に記憶し、抽出のON/OFFはゲーム編集から設定できます。
- 本文をゲーム単位で蓄積し、必要な時だけ自由な名前の区間を作成できます。プレイ中の開始・終了、または保存済み本文の両端指定に対応し、区間外の本文も保持します。
- 抽出画面をアイコン中心の表示へ整理しました。区間指定・修正・設定・通知によって既存の操作位置や本文領域を押し動かさない構成にしています。

## 互換性と配布

- 既存のゲーム登録、設定、セーブデータと同期先を維持します。シナリオ履歴にはゲーム単位の区間管理を追加します。
- アプリ本体の配布ライセンスはGPL-3.0-onlyです。MSIXにはLunaHook等のネイティブ部品とライセンスを含みます。対応ソースとビルド手順を含む `GameLauncherWithGit-v2.1.0-preview.1-source.zip` を添付します。
- MSIXの名前・発行者は既存版と同じです。プレビューをインストールする場合も既存の登録情報を使用します。事前にデータをバックアップしてください。正式版へ移る際も、より大きいMSIX番号のパッケージを使用します。

## 確認状況

- 対応ソースと同じ構成の隔離コピーで、Git管理情報のない状態から同梱MinHook/uchardetを使い、Host・Hook・注入helperの32/64bit Releaseビルドが成功しました。そのコピーからWindows x64向けRelease MSIXを生成しています。
- MSIXの署名検証・展開が成功し、名前・発行者の既存版との一致、番号 `2.0.0.0` から `2.1.0.18` への増加、x64パッケージ、32/64bitネイティブ部品とライセンスの同梱を確認しました。既存 `v2.0.0` と同じ署名証明書を使用しています。これは実際のインストール・更新の成功を確認したものではありません。
- シナリオ保存・分類13件とGit関連6件の自動テストがRelease構成で成功しました。
- 抽出UIは隔離した実Razor画面で1280/700/390pxの描画・操作を確認しています。Windows Debugビルドとシナリオ保存・分類の自動テスト13件も成功しています。
- 「創作彼女の恋愛公式」の32bit本体でHOOKの実受信、保存、話者設定、修正、TXT出力を確認しています。この確認は区間管理・最終UI更新前の実装に対するものです。
- 最終UIのnative WebView固有の描画、最新パッケージのインストール・更新、実ゲームでの最終操作、他作品と長時間負荷は未確認です。

## 既知の制限

- 取得はベストエフォートです。全作品対応、全文章の取得、画面との完全一致、未取得文の復元は保証しません。OCR・翻訳は提供しません。
- 大量スキップや高速な文章送りでは複数発言・名前が連結する場合があります。曖昧な話者は未確定として扱い、推測で割り当てません。
- HOOKはゲームプロセスへDLLを注入します。信頼できるゲームだけへ接続してください。
- ビルドではOpenTelemetry Exporterの既知の中程度の脆弱性警告が残っています。現在はファイルログのみを使用し、OTLP exporterは登録していません。依存更新は [Issue #21](https://github.com/natumekazuki/GameLauncherWithGit/issues/21) で別途管理しています。
- 復元対象のAndroidワークロードについてサポート終了の警告が出ます。本プレビューの配布・確認対象はWindows x64のみです。また、`mspdbcmf.exe` が見つからないためシンボルパッケージは生成していません。MSIX本体の生成・署名は成功しています。
